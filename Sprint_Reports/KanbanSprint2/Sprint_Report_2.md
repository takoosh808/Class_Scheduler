# Sprint 2 Report 
Video Link: https://www.youtube.com/watch?v=IkltBb2ZpK4
## What's New (User Facing)
 * Ability to search for courses in the UI
 * Improvements to the login system
 * Backend ability to handle new courses and student registration

## Work Summary (Developer Facing)
In this sprint, we were focused on integrating our backend and frontend, which we developed in Sprint 1. We did not accomplish as much as we intended due to very busy schedules during the duration of the sprint. One thing we focused on improving was our teamwork and communication. Last sprint we worked on different parts of the application (front,back,db) but for this sprint we worked better as a team and were able to complete the increasingly complex user stories.

## Unfinished Work
We were expected to complete around 75% of the user stories in this sprint, but realized that most of our user stories relied on fetching and sending data from the front to the back, so we implemented the backend processing while working on setting up our REST API so that we could implement all of our features in the final sprint.

## Retrospective Summary
Here's what went well:
  * We worked much more collaboratively and shared ideas more frequently
  * We utilized better version control practices by pushing more frequently and reviewing pull requests
  * We worked through problems much more efficiently then last sprint
 
Here's what we'd like to improve:
   * Not having to rush at the end of the sprint to get a presentable product
   * Meet more frequently throughout the sprint
  
Here are changes we plan to implement in the next sprint:
   * Have preselected days to meet and have standup
   * Dedicated times for when each feature should be completed (every 3-4 days)
